# Монтажная Империя — Лендинг

Фронтенд одностраничного сайта для компании «Монтажная Империя» (Владивосток) — монтаж систем безопасности, видеонаблюдения, СКУД, пожарной сигнализации и СКС.

Вёрстка выполнена строго по макету из Figma с полной адаптивностью под три контрольные точки: Desktop (1440px), Tablet (760px) и Mobile (360px).

---

## Быстрый старт

Требуется Node.js 18+.

```bash
# Установка зависимостей
npm install

# Запуск локального сервера для разработки
npm run dev

# Сборка продакшен-версии в папку dist
npm run build

# Локальный просмотр собранной версии
npm run preview
```

Локальный dev-сервер по умолчанию стартует на `http://localhost:5173`. Чтобы открыть сайт с телефона или другого устройства в локальной сети, используйте флаг `--host`:
```bash
npm run dev -- --host 0.0.0.0
```

## Стек технологий

* **Сборщик:** Vite 5 — мгновенная горячая перезагрузка (HMR) и оптимизированная сборка.
* **Стили:** Tailwind CSS 3 + PostCSS. Дополнительные эффекты (амбиентные градиенты, скошенные срезы плашек под 45°, HUD-элементы) вынесены в `src/style.css`.
* **Скрипты:** Чистый JavaScript (Vanilla ES-модули) без сторонних тяжелых библиотек. Суммарный вес сжатого JS-бандла — всего ~10.7 кБ.
* **Шрифты:** Fira Sans Extra Condensed (заголовки), Onest (основной текст), JetBrains Mono (технические бейджи и таймкоды).

## Особенности реализации

1. **Фоновое видео в первом экране:**
   Оригинальное видео из макета сконвертировано в два формата (`.webm` и `.mp4`) с масштабированием в 1080p через Lanczos. Звуковая дорожка вырезана на уровне контейнера, чтобы браузеры не блокировали автоплей. Выставлены частые ключевые кадры (`-g 24`), благодаря чему видео зацикливается мгновенно, без рывка и черного кадра.

2. **Горизонтальный скролл (Секция 05):**
   На экранах шире мобильных карточки отраслей фиксируются на экране и прокручиваются горизонтально по мере вертикального скролла страницы. Под ними идет бегущая строка банков, которая ускоряется при скролле вниз, притормаживает при скролле вверх и встает на паузу при наведении курсора.

3. **Колода карточек (Секция 06):**
   Выполненные кейсы сверстаны в виде стопки наложенных друг на друга карточек (эффект глубины). Клик по карточке на заднем плане или по вкладке вверху перекладывает стопку и перезапускает счетчики одометра.

4. **Интерактивные этапы (Секция 04):**
   Центральный 3D-рендер серверного шкафа плавно наклоняется в перспективе вслед за движением мыши. Подсветка шагов работает во взаимоисключающем режиме: при наведении мыши подсвечивается текущий шаг, а при уводе мыши фокус возвращается к шагу по центру экрана.

5. **Формы и валидация:**
   На всех телефонных инпутах работает строгая маска `+7 (XXX) XXX-XX-XX`. При начале ввода автоматически подставляется префикс `+7 (`, при вставке номера с восьмерки или девятки цифры нормализуются. Если номер не допечатан, поле подсвечивается красной рамкой, а отправка блокируется.

6. **Аккордеон FAQ:**
   Анимация высоты сделана через CSS Grid (`grid-template-rows: 0fr -> 1fr`). Это решает классическую проблему JavaScript-аккордеонов: текст появляется плавно, без прыжков верстки и без костылей с `max-height`.
