# Монтажная Империя — Системы безопасности и слаботочные сети

Современный адаптивный лендинг для компании **«Монтажная Империя»** (г. Владивосток), разработанный в точном соответствии с дизайн-макетом Figma.

## 📌 О компании и проекте
- **Компания:** ООО «Монтажная Империя» (Владивосток и Приморский край).
- **Специализация:** Комплексная безопасность, IP-видеонаблюдение, СКУД, охранно-пожарная сигнализация (АПС/СОУЭ), структурированные кабельные сети (СКС/ВОЛС), электромонтаж.
- **Дизайн-система:** Темная техническая эстетика (`#0E1014`, `#14171D`, `#E02D37`), моноширинные технические бейджи JetBrains Mono, типографика Fira Sans Extra Condensed и Onest.

## 🚀 Стек технологий
- **Сборщик:** [Vite 5](https://vitejs.dev/)
- **Стилизация:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Иконки:** [Lucide Icons](https://lucide.dev/) (оптимизированный tree-shaken бандл 13 кБ)
- **Шрифты:** Google Fonts (`Fira Sans Extra Condensed`, `JetBrains Mono`, `Onest`, `Sofia Sans Condensed`)

## 📐 Реализованные адаптивные разрешения
- **Desktop (1440px):** Полноразмерная сетка, интерактивный HUD, таймер времени записи REC, калькулятор сметы.
- **Tablet (760px):** Адаптивная двухколоночная сетка карточек, плавная трансформация блоков.
- **Mobile (360px):** Компактный режим с выезжающим боковым бургер-меню (drawer), оптимизированные формы и кнопки.

## 🧩 Разделы и функционал
1. **Top HUD Bar:** Мигающий индикатор `● REC`, живой счетчик таймкода видеозаписи, телефон и режим работы.
2. **Header:** Фирменный логотип с перекрестьем прицела CCTV, навигация по якорям, кнопка «Оставить заявку», мобильный бургер.
3. **Hero:** Технические инфо-теги `[БИЗНЕСУ И ЧАСТНЫМ КЛИЕНТАМ]`, крупный акцидентный заголовок, призыв к действию.
4. **Marquee Ticker (Бегущая строка):** Бесконечная плавная строка `#E02D37` со списком ключевых направлений.
5. **01 / Экспертиза:** Карточки с преимуществами (бесплатный выезд и смета, 3 года гарантии, собственный склад).
6. **02 / Направления и услуги:** 6 детализированных карточек с векторной графикой и тегами брендов (CCTV, СКУД, Сигнализация, АПС, СКС, Электромонтаж).
7. **03 / Оборудование и бренды:** Партнерская сетка вендоров (Hikvision, Dahua, Sigur, Болид, Рубеж, Trassir, Parsec, DKC, Legrand, Suprema).
8. **04 / Этапы работы:** Пошаговая временная шкала (01–05) от аудита до сдачи под ключ.
9. **05 / Объекты и статистика:** Редакционный заголовок с фото-пилюлями инженера и камеры, ключевые метрики (500+ объектов, 10+ лет).
10. **06 / Выполненные кейсы:** Карточки сданных объектов (БЦ Сбербанк, логистический хаб в г. Артём).
11. **07 / Калькулятор сметы и лид-форма:** Интерактивный переключатель направлений с динамическим расчетом бюджета, маской номера телефона `+7 (___) ___-__-__` и модальным окном подтверждения.
12. **08 / FAQ:** Интерактивный аккордеон с ответами на ключевые вопросы.
13. **Footer:** Юридические реквизиты, карта, контакты, лицензия МЧС России.
14. **404 Page (`/404.html`):** Кастомная страница ошибки с техническим сообщением «NO VIDEO FEED // СИГНАЛ ПОТЕРЯН».

## 🛠 Запуск проекта локально

### Установка зависимостей:
```bash
npm install
```

### Запуск сервера разработки:
```bash
npm run dev
```

### Сборка для продакшена:
```bash
npm run build
```

### Предпросмотр сборки:
```bash
npm run preview
```
