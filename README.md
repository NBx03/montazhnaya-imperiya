# Монтажная Империя — Системы безопасности и слаботочные сети

Современный высокопроизводительный адаптивный лендинг для компании **«Монтажная Империя»** (г. Владивосток), разработанный в точном соответствии с дизайн-макетом Figma (Pixel-Perfect, 1440px / 760px / 360px).

> 📘 **Для разработчиков и нейросетей:** Подробная архитектура проекта, карта секций, описание модулей JS и токены дизайн-системы описаны в [ARCHITECTURE.md](./ARCHITECTURE.md).

---

## 🚀 Стек технологий

* **Сборщик:** [Vite 5](https://vitejs.dev/)
* **Стили:** [Tailwind CSS 3](https://tailwindcss.com/) + PostCSS + кастомная дизайн-система (`src/style.css`)
* **Архитектура скриптов:** Чистые Vanilla JS ES-модули (`src/js/modules/`)
* **Шрифты:** Google Fonts (`Fira Sans Extra Condensed`, `Onest`, `JetBrains Mono`)
* **Медиа:** H.264 (MP4) + VP9 (WebM) без звука с закрытой структурой ключевых кадров для бесшовного зацикливания

---

## 🧩 Реализованный функционал

1. **Header & Navigation:** Скрывается при скролле вниз, появляется при скролле вверх. Боковая шторка мобильного бургер-меню с блокировкой скролла.
2. **Hero Section:** Зацикленный видеофон высокой чёткости (1080p Lanczos), тикающий таймер видеонаблюдения `REC`, динамическая дата `hero-date`, технические HUD-прицелы.
3. **01 / Экспертиза:** Карточки преимуществ с каскадным таймлайн-появлением.
4. **02 / Направления и услуги:** 7 технических направлений, графитовая плашка с интерактивным баннером «Не нашли свою задачу?».
5. **03 / Почему мы:** Статистические счетчики с анимацией механического одометра.
6. **04 / Этапы работы:** Интерактивный 3D-тилт оборудования за курсором мыши, взаимно-исключающий hover и scroll-spy шагов.
7. **05 / Область работы:** Фиксация экрана с горизонтальной прокруткой 4 сфер + динамический тикер банков (ускоряется при скролле вниз, замедляется при скролле вверх, замирает при наведении).
8. **06 / Выполненные кейсы:** Интерактивная 3D-колода наложенных карточек с переключением глубины (front/middle/back) и пересчетом одометра.
9. **07 / Частые вопросы & Консультация:** Аккордеон вопросов с маскированным появлением текста + форма заявки с фото инженера.
10. **Модальные окна:** Модалка консультации «Обсудим ваш проект?», модалка «Заявка отправлена» с кнопкой «На главную».
11. **Валидация:** Строгая маска телефона `+7 (999) 123-45-67` на всех полях ввода с автокоррекцией и подсветкой ошибок.
12. **Страница 404 (`/404.html`):** Автономная страница ошибки в техническом стиле «NO VIDEO FEED».

## 🛠 Быстрый запуск

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev -- --host 0.0.0.0
```

### Сборка продакшен-бандла:
```bash
npm run build
```

### Предпросмотр сборки:
```bash
npm run preview
```
