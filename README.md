# Монтажная Империя

Сайт и панель управления для компании «Монтажная Империя» (Владивосток): монтаж систем безопасности, видеонаблюдения, СКУД, пожарной сигнализации, СКС и электромонтажа.

Проект состоит из статического лендинга на Vite + Tailwind, бэкенда на FastAPI со встроенной SQLite-базой и SPA-админки (`/admin/`), откуда управляются заявки, тексты и медиафайлы на сайте без пересборки фронтенда.

---

## Стек

- **Frontend:** HTML5, Tailwind CSS 3, Vanilla JS (11 ES-модулей в `src/js/modules/`), сборка через Vite 5 (`index.html`, `privacy.html`, `404.html`).
- **Backend:** Python 3.11+, FastAPI, SQLAlchemy (async) + SQLite в режиме WAL (`aiosqlite`), Pydantic v2.
- **Админ-панель:** отдельный SPA на чистом JS/CSS (`backend/static_admin/`), отдаётся самим FastAPI на `/admin/`.
- **Защита и медиа:** JWT (`pyjwt`) + `bcrypt`, лимитер запросов `slowapi`, проверка magic bytes загружаемых файлов, пережатие картинок в WebP через Pillow, поддержка loop-видео (MP4/WebM до 25 МБ).
- **Инфраструктура:** Caddy 2 (`Caddyfile.production`), systemd-юниты, горячие бэкапы SQLite (`.backup` + `gzip`, ротация 14 дней).

## Быстрый старт (локально)

Потребуются **Node.js 18+** и **Python 3.11+**.

### 1. Бэкенд и админка (порт `8000`)

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
python manage.py seed
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

После запуска:
- API и документация: `http://127.0.0.1:8000/docs`
- Админ-панель: `http://127.0.0.1:8000/admin/` (логин и пароль по умолчанию задаются в `.env`).

### 2. Фронтенд (порт `5173`)

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Сборка продакшен-бандла в `dist/`:

```bash
npm run build
npm run preview
```

## Что умеет система

- **Динамическая гидрация лендинга:** `src/js/modules/content-loader.js` при загрузке страницы тянет актуальный JSON из `GET /api/v1/content` с кэшем в `sessionStorage` и условными запросами `ETag` / `304 Not Modified`. Если API недоступен, остаётся статический HTML из `index.html`.
- **Управление заявками (`📋 Входящие заявки`):** приём форм с маской `+7 (XXX) XXX-XX-XX`, скрытое honeypot-поле против спам-ботов, rate-limit, заметки менеджера, смена статуса (`Новая` / `Обработана`), поиск и выгрузка в CSV (UTF-8 BOM, с защитой от CSV formula injection).
- **Редактор текстов (`✍️ Тексты и контакты`):** редактирование всех 11 секций (телефоны с автосинхронизацией `tel:`, тарифы, этапы, кейсы, FAQ, реквизиты) с клиентской и серверной Pydantic-валидацией.
- **Визуальный медиа-менеджер (`🖼️ Медиа сайта`):** замена всех 37 медиа-слотов сайта (логотипы, иконки, фото, 3D-рендеры, фоновое видео Hero) через Drag & Drop или выбор файла, плюс сброс любого слота к стандартному ассету.
- **История медиа и быстрый откат (`🕘 История медиа`):** все загруженные файлы сохраняются в таблице `media_assets` с привязкой к слоту и исходным именем файла — прошлую картинку или видео можно вернуть на сайт в один клик как из общей вкладки истории, так и прямо из карточки слота.
